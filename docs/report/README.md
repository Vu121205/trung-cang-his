# Tài liệu báo cáo thực tập

Thư mục này chứa toàn bộ đầu ra của báo cáo, tách biệt với mã nguồn ứng dụng.

- `bao-cao-thuc-tap.md`: nguồn Markdown chính để rà soát nội dung.
- `diagrams/`: nguồn sơ đồ PlantUML có thể chỉnh sửa.
- `assets/diagrams/`: ảnh SVG/PNG xuất từ sơ đồ.
- `assets/screenshots/`: ảnh giao diện được chụp bằng Playwright trên dữ liệu H2 TEST.
- `references/`: tài liệu tham khảo và thông tin truy vết nguồn.

Các ảnh giao diện chỉ được chụp sau khi chạy ứng dụng với H2 trong bộ nhớ. Không dùng bệnh nhân hay dữ liệu MySQL thật.
